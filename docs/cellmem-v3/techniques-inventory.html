v3 Design Decisions

Memory granularity Hybrid (per-token K/V write, episode retrieval via router)
Layer placement Configurable, default top-4
K/V storage Per-layer pre-computed pre-RoPE (0.5 MB)
RoPE handling Pre-RoPE (position-agnostic, "timeless post-it")
LoRA Eliminated. Only router projectors W_Q^R, W_K^R
Router training Contrastive InfoNCE loss, two-phase (MSA-style)

Kept

6 techniques unchanged from v2
Surprise-gated writes (BTSP) Paper
Write only surprising tokens. Anti-Hebbian pure.
Source: NIMH/Scripps 2025, Bhatt et al. — BTSP anti-Hebbian plasticity in CA1
SurpriseCalculator Paper
Per-token cross-entropy. Catches "confident but wrong".
Source: NIMH/Scripps 2025 — Prediction error as write signal
Decay on load Original
vectors *= decay_factor on cross-session load. Natural forgetting.
Source: Original CellMem — Inspired by memory consolidation during sleep
Snapshot + rollback Original
Periodic backups for recovery.
Source: Original CellMem — Pragmatic engineering
Decorrelation gate Neuroscience
min_novelty: skip write if too similar to existing memories. Pattern separation.
Source: Neuroscience — Dentate Gyrus pattern separation in hippocampus
Delta writes Paper
Write prediction error instead of raw vector. Configurable write_mode="delta".
Source: Infini-attention, Munkhdalai et al. 2024 (arXiv:2404.07143) — Delta update rule

Evolved

5 techniques — same principle, different form
MemoryStore Paper
Storage format redesigned for native K/V with per-layer granularity.
v2
hidden states [K, d_model]
→
v3
K/V per-layer [L, N, d_head] pre-RoPE
Source: MSA (arXiv:2603.23516) — K/V storage with mean pooling
Two-phase training Paper
Training schedule evolved from gate freezing to loss-weighting warmup.
v2
Phase 1 gate frozen (LoRA learns), Phase 2 gate unfrozen + BCE
→
v3
Phase 1 warmup 0.1*L_LM + L_contrastive, Phase 2 main L_LM + 0.1*L_contrastive
Source: MSA — Warmup + main phase training schedule
Auxiliary loss
Paper Paper
Moved from scalar BCE to contrastive InfoNCE in embedding space.
v2
BCE(gate, 0.9/0.1) on scalar
→
v3
InfoNCE(Q^R, K^R) contrastive in embedding space
Source: MSA (InfoNCE routing loss) + LeWorldModel (arXiv:2603.19312, "don't rely on task loss alone")
Init ≠ zero Original
Non-zero initialization preserved; adapted from LoRA matrices to router projectors.
v2
lora_B ~ N(0, 1e-3)
→
v3
W_Q^R, W_K^R ~ N(0, 0.02)
Source: Original CellMem lesson from v2 — Zero-init blocks gradient via chain rule
Max vector norm Original
Norm clamping to validate; smaller norms expected with K/V.
v2
Clamp norm on hidden states
→
v3
To validate on K/V (smaller norms expected)
Source: Original CellMem — Explosion prevention

Dropped

5 techniques no longer needed
ContentGate (CA1 tonic+phasic) Paper
Scalar gate sigmoid(base + MLP(...)) — replaced by router top-k.
Was from: NIMH/Scripps — CA1 principle remains in surprise writes, not in gate
Reason: Gradient diluted through 18 layers, collapsed to 0.1, impossible to discriminate pos/neg
Pupil range [0.1, 0.9] Original
0.1 + 0.8 * sigmoid(x) — no more sigmoid.
Was from: Original CellMem — Pupil metaphor
Reason: Router doesn't use sigmoid, uses cosine similarity + discrete top-k
Canal lock clamp Original
base.data.clamp_(-2, 2) — no more scalar_base.
Was from: Original CellMem — Lock metaphor
Reason: Router has no scalar parameter to clamp
LoRA (q_proj, v_proj) Paper
K/V pre-RoPE are already native format — no adapter needed.
Was from: Hu et al. 2021 — LoRA paper
Reason: No need to adapt backbone, K/V already speak its language
MemoryRMSNorm Original
K/V already normalized by backbone layer norm.
Was from: Original CellMem
Reason: Protection for noisy hidden states. K/V are clean
